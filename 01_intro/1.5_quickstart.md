## 1.5 五分钟快速上手：API 与 Claude Code CLI

完成模型认知和选型框架后，最好立刻亲手跑通第一轮真实交互，再进入第二章的提示工程练习。本节提供三条互不冲突的 5 分钟闭环路径：Web 对话、Python Messages API 和 Claude Code CLI。

### 1.5.1 路径 A：Web 端首次对话（1 分钟）

如果你还没有配置开发环境，打开 [claude.ai](https://claude.ai) 登录账号，直接输入一段带明确约束的任务，观察输出是否按结构返回：

```text
请用不超过 100 字解释“什么是提示词缓存”，并给出一个适合开发者的类比。
```

拿到回复后，你可以继续在同一对话里追加约束（例如“改写成 JSON，包含 summary 和 analogy 两个字段”），直观感受 Claude 对结构化指令的响应方式。

### 1.5.2 路径 B：Python Messages API 首次调通（3 分钟）

适合计划在应用或脚本中调用 Claude 的开发者。

**第 1 步：准备虚拟环境并安装官方 SDK**

```bash
python3 -m venv .venv && . .venv/bin/activate
python3 -m pip install anthropic
```

如果想直接运行并测试本书仓库自带的离线黄金路径示例，也可以安装锁定的示例依赖：

```bash
python3 -m pip install -r examples/requirements.txt
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

**第 2 步：通过环境变量提供 API Key**

在 [Anthropic Console](https://console.anthropic.com/) 创建 API Key 后，将其写入当前终端环境变量（切勿把真实密钥写进代码或提交到 Git 仓库）：

```bash
export ANTHROPIC_API_KEY="your-api-key"
```

**第 3 步：发出第一条消息并安全解析响应**

将下面代码保存为 `hello_claude.py` 并运行 `python3 hello_claude.py`：

```python
import anthropic

client = anthropic.Anthropic()  # 自动读取环境变量 ANTHROPIC_API_KEY

response = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "用一句话解释 Claude Messages API。"}],
)

if response.stop_reason == "refusal":
    raise RuntimeError("请求触发了模型拒绝，请检查输入或走回退逻辑。")

text = "".join(block.text for block in response.content if block.type == "text")
print(text)
```

这段最小代码从第一天起就遵循两条生产习惯：

*   **按块类型读取文本**：`claude-sonnet-5-5` 默认开启 Adaptive Thinking，响应的 `content` 列表里可能同时包含 `thinking` 块与 `text` 块，因此不要假设 `response.content[0]` 一定是文本。
*   **显式检查 `stop_reason == "refusal"`**：安全分类器拒绝请求时仍返回 HTTP 200，需要由业务代码主动分支处理。

本书仓库中的 [examples/messages_api.py](../examples/messages_api.py) 封装了同一条最小调用路径（并支持注入 mock 传输做离线单测）；完整的多语言参数和流式示例见 [附录 A：API 参考手册](../12_appendix/12.1_api_ref.md)。

### 1.5.3 路径 C：Claude Code CLI 首次调通（2 分钟）

如果你想直接在终端里让 Claude 读代码、排查报错或做重构，可以安装 Claude Code CLI。

**第 1 步：安装 CLI**

macOS、Linux 或 WSL 推荐使用原生安装器或可审计的系统包管理器：

```bash
# macOS（Homebrew）
brew install --cask claude-code

# 或原生安装脚本（受管环境建议先下载审阅再执行）
curl -fsSL https://claude.ai/install.sh | bash
```

**第 2 步：进入任意本地项目目录并启动**

```bash
cd /path/to/your-project
claude
```

首次运行会引导浏览器完成登录（需要具备 Claude Code 权限的订阅或 Console 账号）。登录成功后，先从一条只读问题开始，确认终端工具链路正常：

```text
> 用 3 条要点总结当前仓库的目录结构与测试入口，不要修改任何文件。
```

更完整的认证优先级、权限边界、无头模式（Headless）与日常运维命令，请参阅 [7.2 Claude Code CLI 入门与基础运维](../07_coding/7.2_cli.md)。

### 1.5.4 首轮排障速查

| 现象 | 常见原因 | 快速排查方向 |
| :--- | :--- | :--- |
| `401 AuthenticationError` | 未导出 `ANTHROPIC_API_KEY` 或密钥无效 | 运行 `echo ${#ANTHROPIC_API_KEY}` 确认当前 shell 已加载变量，切勿在日志中打印明文 |
| `400 BadRequestError` | 传入了新版 API/模型不支持的参数 | API 版本 `2026-10-21` 已移除 `temperature`/`top_p`/`top_k`；5.5 模型不接受手动 `thinking: {"type": "enabled"}` |
| 输出为空字符串 | 只读取了 `content[0]` 而首个块是 `thinking` | 改为遍历 `response.content` 并过滤 `block.type == "text"` |
| `stop_reason == "refusal"` | 请求触发安全分类器拒绝 | 丢弃不完整输出并记录拒绝指标，详情见 [附录 G](../12_appendix/12.7_volatile_facts.md) |
