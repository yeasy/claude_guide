# 第一章 认识 Claude

学习 Claude 的各项技能之前，需要先建立整体认知。本章介绍：

- Anthropic 公司的创立背景与使命
- Claude 模型家族的演进历程
- Claude 具备哪些核心能力
- 如何根据场景选择合适的模型

---

## 本章概览

Claude 是一个 **模型家族**。从 2023 年首次发布到 2026 年，Claude 经历了多次重大迭代，能力边界不断扩展。

理解能力边界是高效使用 Claude 的前提。用户觉得 Claude “不够聪明”或“无法完成任务”，原因往往是：

1. **选错了模型**：用快速模型处理复杂推理任务
2. **忽略了能力**：不知道 Claude 可以调用工具、操作计算机
3. **提示不当**：没有给 Claude 足够的上下文和指导

本章帮助读者建立完整的 Claude 能力地图。
