## 附录 H：Claude 版本演进与迁移历史

本附录集中收录从第一章精简下沉的历史型号演进记录、各版本破坏性变更与旧版对比，供维护存量代码或查阅迁移背景时使用。当前推荐型号、最新定价与弃用日期请始终以 **[附录 G：快变事实核验表](12.7_volatile_facts.md)** 和 [Anthropic 官方文档](https://platform.claude.com/docs/en/about-claude/models/migration-guide)为准。

### H.1 完整版本演进记录

#### 早期探索：Claude 1 与 2

*   **Claude 1（2023.03）**：Anthropic 的首次亮相。相比当时的 GPT-3.5，它更遵循约束，也更少产生胡编乱造。
*   **Claude 2（2023.07）**：Anthropic 已于 2023 年 5 月率先把上下文窗口从 9K 扩展到 **100K Token（约 7.5 万单词）**（Claude 1.3 代即可用），Claude 2 将这一能力带给更广泛的公众，带动了 PDF 阅读和长文档分析需求。

#### 产品矩阵成形：Claude 3 与 3.5 / 3.7

*   **Claude 3（2024.03）**：正式确立 Opus / Sonnet / Haiku 产品矩阵，全系支持视觉输入（Vision）；Claude 3 Opus 在发布时成为新的 SOTA 模型。
*   **Claude 3.5 Sonnet（2024.06 / 2024.10）**：以中等模型的成本和速度超越上一代旗舰，并先后引入 **Artifacts** 与 **Computer Use（计算机操控）**。
*   **Claude 3.7 Sonnet（2025.02.24）**：Anthropic 首个支持 **Extended Thinking（扩展思考）** 的模型，开创混合推理模式，为后续 Claude 4 系列的推理架构奠定基础。

#### 第四代：Claude 4 系列

*   **Claude Opus 4 / Sonnet 4（2025.05）**：推理与自主行动能力大幅跃升；Anthropic 作为预防性措施在 ASL-3 防护标准下部署 Opus 4（官方明确并未认定其跨过 ASL-3 能力阈值）。
*   **Claude Opus 4.1（2025.08）**：面向 Agentic 编码的增量升级，SWE-bench Verified 从 72.5% 提至 74.5%。注：Claude Opus 4 已于 2026-04-14 弃用、2026-06-15 退役；Claude Opus 4.1 已于 2026-06-05 弃用、2026-08-05 退役，新项目建议直接选用 Opus 5.5。
*   **Claude Sonnet 4.5（2025.09）**：能力匹配 Opus 4.1 且价格更低，曾成为部署最广泛的模型；后于 2026-09-30 宣布弃用，2026-11-30 在 Claude API 退役。
*   **Claude Haiku 4.5（2025.10）**：以约 4–5 倍速度提供高性价比编码与提取能力（Claude 3 Haiku 已于 2026-02-19 弃用、2026-04-20 退役；新项目应直接使用 Haiku 5.5）。
*   **Claude Opus 4.5（2025.11）**：编码、Agent 和 Computer Use 能力进一步提升且价格大幅下调；后于 2026-11-23 宣布弃用，计划 2027-01-22 退役。
*   **Claude Opus 4.6 / Sonnet 4.6（2026.02）**：均支持 **1M Token 上下文窗口**；Sonnet 4.6 在保持 $3/$15 定价的同时全面升级。
*   **Claude Opus 4.7（2026.04）**：在高难度软件工程、视觉分辨率和多步一致性上较 4.6 显著提升（发布说明基准：SWE-bench Verified 87.6% vs 80.8%，Terminal-Bench 2.0 69.4% vs 65.4%，GPQA Diamond 94.2% vs 91.3%，Finance Agent 64.4% vs 60.7%）；采用新 tokenizer，同一文本可能消耗 1.00–1.35 倍 token。
*   **Claude Opus 4.8（2026.05.28）**：发布时为最强 GA 模型（此后依次由 Fable 5 / 5.1 / 5.2 与 Opus 5 / 5.5 接棒，4.8 与 4.7、4.6 一并转入 Legacy models）。沿用 $5/$25 定价、1M 上下文与 128K 最大输出，仅支持 Adaptive Thinking，`effort` 默认 `high`，引入研究预览 Fast mode（将于 2026-11-30 移除）与 1,024 token 最小缓存前缀，模型 ID 为 `claude-opus-4-8`。
*   **Claude Mythos Preview（2026.04）**：面向防御性网络安全的前沿研究预览模型，并由此启动 Project Glasswing 计划，仅通过邀请制提供（$25/$125），不公开发售。

#### 第五代：Claude 5 与 5.x 迭代

*   **Claude Fable 5 / Mythos 5（2026.06）**：Fable 5（`claude-fable-5`，$10/$50，1M 上下文、128K 输出）在 6 月 12 日暂停后于 2026-07-01 恢复全球访问；Mythos 5（`claude-mythos-5`）非普遍可用，仅向 Project Glasswing 获批客户有限开放（无自助注册）。生产路由需显式处理 `stop_reason: "refusal"`。
*   **Claude Sonnet 5（2026.06）**：API ID 为 `claude-sonnet-5`，1M 上下文、128K 输出，Adaptive Thinking 默认开启；标准价 $2/$10（官方已取消原定 2026-09-01 上调至 $3/$15 的计划）。它是 Sonnet 4.6 的迁移目标，2026-09-28 起由 Sonnet 5.5 接替并转入 Legacy models。
*   **Claude Opus 5（2026.07.24）**：API ID 为 `claude-opus-5`，$5/$25、1M 上下文、128K 输出、可靠知识截止 2026 年 5 月。相比 4.8 的破坏性变更包括：**Thinking 默认开启**（须重估 `max_tokens`），且 `thinking: {type: "disabled"}` 仅在 `effort` 为 `high` 及以下时接受（搭配 `xhigh`/`max` 返回 400）。另降低最小可缓存前缀至 512 token，并新增 `mid-conversation-tool-changes-2026-07-01` beta 与 `fallbacks: "default"`；Opus 5 会自行验证结果，旧的“最后再检查一遍”提示可删除。2026-09-22 起由 Opus 5.5 接替并转入 Legacy models。
*   **Claude Fable 5.1（2026.09.01）**：API ID 为 `claude-fable-5-1`，$10/$50，缓存读取降至基础输入的 2.5%，强制工具调用（`tool_choice` 为 `any` 或 `tool`）返回 400；后由 Fable 5.2 接替并转入 Legacy models。同日发布的 Mythos 5.1 仅限 Project Glasswing 参与者。
*   **Claude Opus 5.5（2026.09.22）**：API ID 为 `claude-opus-5-5`，$4/$20，缓存读取为基础输入的 5%，接替 Opus 5 成为官方默认起点。相比 Opus 5 的破坏性变更：**thinking 常开、不可关闭**（`disabled` 与手动 `enabled` 均返回 400）；**默认 `effort` 降为 `medium`**；强制工具调用返回 400；在 Claude API 与 Google Cloud 上，computer use 只接受 `computer_toolset_20260801`。
*   **Claude Sonnet 5.5（2026.09.28）**：API ID 为 `claude-sonnet-5-5`，$2/$10，tokenizer 与 Sonnet 5 相同。Adaptive Thinking 默认开启；`thinking: {type: "disabled"}` 返回 400，关闭动手前思考需改用 `thinking: {type: "between_tools"}`（仅限 `effort` 为 `high` 及以下）；强制工具调用返回 400。
*   **Claude Haiku 5.5（2026.10.07）**：API ID 为 `claude-haiku-5-5`，1M 上下文、128K 输出，Adaptive Thinking 默认开启（`disabled` 仅接受 `effort <= high`），拒绝手动 `budget_tokens`、非默认 sampling 参数、assistant 预填充与旧版 `computer_20250124`。
*   **Claude Fable 5.2 / Mythos 5.2（2026.11.09）**：Fable 5.2（`claude-fable-5-2`）单价降至 $8/$40、缓存读取 2.5%（$0.20），默认 `effort` 为 `high`，强制工具调用与 assistant 预填充返回 400；相比 Fable 5.1 的破坏性变更为：改动 `system`、`tools` 或更早消息后再回传后续轮次 thinking 块对所有账号返回 400，且除 Amazon Bedrock 外 computer use 只接受 `computer_toolset_20260801`。Mythos 5.2 规格与价格相同，仅向通过 Anthropic 验证项目的组织开放。

### H.2 各型号 Thinking 模式兼容矩阵

*   **Claude Fable 5.2 / 5.1 / Fable 5**：**Adaptive Thinking** 常开，不可关闭，不支持手动 Extended Thinking。
*   **Claude Opus 5.5**：**Adaptive Thinking 常开、不可关闭**，`thinking={type: "disabled"}` 与手动 `type: "enabled"` 均返回 400；仅用 `effort` 控制深度（默认 `medium`）。
*   **Claude Sonnet 5.5**：**Adaptive Thinking 默认开启**；`thinking={type: "disabled"}` 返回 400，关闭动手前思考改用 `thinking={type: "between_tools"}`（仅限 `effort` 为 `high` 及以下）；手动 Extended Thinking 返回 400。
*   **Claude Haiku 5.5**：**Adaptive Thinking 默认开启**；`thinking={type: "disabled"}` 仅在 `effort` 为 `high` 及以下时接受，手动 Extended Thinking 返回 400。
*   **Claude Opus 5（Legacy）**：**Adaptive Thinking 默认开启**；`thinking={type: "disabled"}` 仅在 `effort` 为 `high` 及以下时接受，不支持 Extended Thinking。
*   **Claude Sonnet 5（Legacy）**：**Adaptive Thinking 默认开启**，可显式关闭；手动 Extended Thinking 返回 400。
*   **Claude Opus 4.8 / 4.7（Legacy）**：仅支持 **Adaptive Thinking**（不写 `thinking` 字段则不思考），不支持 Extended Thinking。
*   **Claude Sonnet 4.6（迁移兼容性参考）**：支持 **Adaptive Thinking**（推荐）和 **Extended Thinking**（手动 `budget_tokens` 已弃用但仍可用）。
*   **Claude Opus 4.6（Legacy）**：支持 **Adaptive Thinking**（推荐）和 **Extended Thinking**（已弃用但仍可用）。
*   **Claude Haiku 4.5（Legacy）**：仅支持 Extended Thinking（`thinking={type: "enabled"}`），不支持 Adaptive Thinking。

### H.3 历史对比：Claude Sonnet 4.5 vs Claude Sonnet 4.6

> 本小节保留 4.6 发布时从 4.5 迁移的历史参考；当前新项目应评测 Sonnet 5.5，不应将下表作为新默认选型依据。完整的新版迁移步骤见 [13.1 迁移检查清单](../13_advanced/13.1_claude5_preview.md)。

| 维度 | Sonnet 4.5 | Sonnet 4.6 | 提升 |
| :--- | :--- | :--- | :--- |
| **编码与智能体能力** | 强 | 更强 | 官方口径见发布说明（SWE-bench Verified、OSWorld、Terminal-Bench 2.0 等） |
| **长上下文理解** | 200K tokens | 1M tokens | 5 倍提升 |
| **Computer Use** | ✓ 支持 | ✓ 增强 | 更精准的屏幕元素识别与交互 |
| **Agent 规划** | ✓ 支持 | ✓ 改进 | 复杂多步任务自纠正能力更强 |
| **价格** | $3/$15 | $3/$15 | 无变化 |

当时从 4.5 升级到 4.6 的历史考量：已有稳定 4.5 系统可分批灰度验证 API 兼容性；需要 1M 长上下文或更强多步规划的新项目会优先评测 4.6。如今 Sonnet 4.5 已进入退役窗口，存量 4.5/4.6 负载均应按 [13.1 迁移检查清单](../13_advanced/13.1_claude5_preview.md) 直接规划向 Sonnet 5.5 迁移。
